#### Edge and Negative Cases

The test suite includes several negative and boundary cases:

- An empty required field returns `EMPTY_FIELD`.
- A username containing a space returns `USERNAME_CONTAINS_SPACE`.
- A password shorter than 8 characters returns `SHORT_PASSWORD`.
- Two different passwords return `PASSWORDS_DONT_MATCH`.
- A password without a required character type returns `NOT_REQUIRED_CHARS`.
- A password exactly 8 characters long tests the minimum-length boundary.
- A 7-character password tests one character below the boundary.
- `?` is tested as an unsupported special character.
- An empty login username tests `checkLogin()` without requiring database access.
